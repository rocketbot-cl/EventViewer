## How to Use This Module
This module allows you to read and filter entries from the Windows Event Viewer.

1. **Log:** Select the Windows log you want to view. Note that accessing the **Security** log may require administrator permissions.

2. **Source:** Allows you to filter events by source name (for example, `UserModePowerService`).

3. **Event ID:** Allows you to filter entries by event ID.

4. **Event Type:** Select the event type you want to include in the results.

5. **From:** Sets the start date and time to include events generated from that point onward.

6. **To:** Sets the end date and time to include events generated up to that point.

7. **Filtered by message:** The value entered must exactly match the name of the event source (*Source*, for example, `UserModePowerService`) or a specific error code included in the event’s general description. This filter does not support keyword searches or partial text matches.

8. **Maximum records to review:** Specifies the maximum number of records to be queried, starting with the most recent ones. By default, 1,000 records are reviewed.

## Como usar este modulo
Este módulo permite leer y filtrar registros del Visor de eventos de Windows.

1. **Registro:** Selecciona el registro de Windows que deseas consultar. Ten en cuenta que el acceso al registro de **Seguridad** puede requerir permisos de administrador.

2. **Origen:** Permite filtrar los eventos según el nombre de su origen (por ejemplo, `UserModePowerService`).

3. **ID del evento:** Permite filtrar los registros por el identificador del evento.

4. **Tipo de evento:** Selecciona el tipo de evento que deseas incluir en los resultados.

5. **Desde:** Establece la fecha y hora inicial para incluir los eventos generados a partir de ese momento.

6. **Hasta:** Establece la fecha y hora límite para incluir los eventos generados hasta ese momento.

7. **Filtrado por mensaje:** El valor ingresado debe coincidir exactamente con el nombre del origen del evento (*Source*, por ejemplo, `UserModePowerService`) o con un código de error específico incluido en la descripción general del evento. Este filtro no admite búsquedas por palabras clave ni coincidencias parciales de texto.

8. **Máximo de registros a revisar:** Indica la cantidad máxima de registros que se consultarán, comenzando por los más recientes. Por defecto, se revisan 1000 registros.

## Como usar este módulo
Este módulo permite ler e filtrar registros do Visualizador de Eventos do Windows.

1. **Registro:** Selecione o registro do Windows que você deseja consultar. Observe que o acesso ao registro de **Segurança** pode exigir permissões de administrador.

2. **Origem:** Permite filtrar os eventos de acordo com o nome de sua origem (por exemplo, `UserModePowerService`).

3. **ID do evento:** Permite filtrar os registros pelo identificador do evento.

4. **Tipo de evento:** Selecione o tipo de evento que você deseja incluir nos resultados.

5. **Desde:** Define a data e a hora iniciais para incluir os eventos gerados a partir desse momento.

6. **Até:** Define a data e a hora limite para incluir os eventos gerados até esse momento.

7. **Filtrado por mensagem:** O valor inserido deve corresponder exatamente ao nome da origem do evento (*Source*, por exemplo, `UserModePowerService`) ou a um código de erro específico incluído na descrição geral do evento. Este filtro não permite pesquisas por palavras-chave nem correspondências parciais de texto.

8. **Número máximo de registros a serem analisados:** Indica a quantidade máxima de registros que serão consultados, começando pelos mais recentes. Por padrão, são analisados 1.000 registros.
